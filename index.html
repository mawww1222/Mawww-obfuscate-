VM Obfuscator

Obfuscator ini bekerja sepenuhnya di browser Anda. Tidak ada source code yang dikirim ke server manapun.

  • Light — Rename identifier + string encoder dasar.
  • Medium — Tambahan XOR opcode encoding + constant pool terpisah.
  • Strong — Tambahan dummy instruction + scrambled instruction table + multi-layer string encoding.
  • Extreme — Tambahan control-flow wrapping, split constant, checksum integrity check, dan decoder layered.

Output menggunakan VM interpreter sederhana yang merekonstruksi ulang source code Anda pada waktu runtime di dalam Lua environment.
